## Overview

**Luma** is a landing-page design concept for an AI-powered workspace, built to explore how thoughtful visual design and modern frontend development can create a distinctive digital experience.

The design combines an editorial-inspired hero, refined typography, soft natural landscapes, and a clean interface. Animated background visuals and subtle motion effects help bring the page to life without overwhelming the content.

The focus is on the **landing-page experience itself**—its visual identity, layout, motion, and interaction design.

## Design Highlights

- **Cinematic visual direction** — Natural landscapes and immersive background visuals.
- **Editorial typography** — Elegant serif headlines paired with clean, readable supporting text.
- **Smooth animations** — Motion effects and loading transitions that enhance the browsing experience.
- **Minimalist interface** — Generous spacing, restrained colors, and subtle glassmorphism.
- **Conversion-focused layout** — Clear navigation, calls to action, and structured content sections.
- **Responsive design** — An interface designed to adapt across screen sizes.

## Preview

The landing page explores a calm, premium aesthetic built around a simple idea: technology can feel approachable without relying on excessive futuristic visuals.

The visual language uses soft greens, neutral tones, natural scenery, and carefully balanced contrast to keep the experience polished and readable.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Shanuka-Dulshan/luma_ai_landing.git
cd luma_ai_landing
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
